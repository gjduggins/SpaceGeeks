# ADR-001: Add Curiosity Mission to NASA Missions Page

## Context
The NASA Missions page currently lacks information about the Mars Science Laboratory mission and its rover, Curiosity. This mission represents one of NASA's most significant achievements in Mars exploration and should be included in our database.

## Decision
We will add comprehensive information about the Curiosity mission to the NASA Missions page, including mission objectives, key discoveries, technical specifications, and timeline.

## Consequences
- Users will have access to information about one of NASA's most successful Mars missions
- Database will require additional entries for mission data
- Frontend will need to accommodate new mission display requirements
