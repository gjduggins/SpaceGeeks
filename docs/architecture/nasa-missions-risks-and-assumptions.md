# NASA Missions Risks and Assumptions

## Identified Risks

| Risk ID | Risk Description | Probability | Impact | Mitigation Strategy |
|---------|------------------|-------------|--------|-------------------|
| R001 | Communication delay with Earth | High | Medium | Implement autonomous decision-making |
| R002 | Dust storms affecting solar panels | Medium | High | Include nuclear power backup |
| R003 | Terrain obstacles causing mobility issues | Medium | High | Enhanced navigation algorithms |

## Key Assumptions

- Stable communication windows will be available
- Rover hardware will function within specifications
- Scientific instruments will produce valid data
- Mission extensions will be approved
