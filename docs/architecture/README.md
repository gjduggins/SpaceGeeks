# Architecture Documentation

This directory contains architecture documentation for the SpaceGeeks project.

## Overview

SpaceGeeks is a web application built with ASP.NET Core Razor Pages that provides space-themed content and experiences.

## Components

- Web Frontend: ASP.NET Core Razor Pages
- Error Handling: Custom error pages
